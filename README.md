# Maple Lounge

A small browser prototype for a MapleStory fashion/hangout game. Walk around, jump, and sit on the
Rabbit Lamp Chair (it changes color each time, like in game) while the Adriano pet follows you.

**Play:** https://cheyenneatapour.github.io/maple-lounge/

## Controls

| Key | Action |
|---|---|
| ← → / A D | Walk |
| Space / ↑ / W | Jump |
| ↓ / S (near the lamp) | Sit; any move key stands up |
| Click Adriano | Pet him |

## How it works

- `index.html` is the whole game: a canvas, movement, pet follow logic, and the chair.
- `assets.js` holds the sprites as base64 data, generated by `build_assets.py`.
- `build_assets.py` downloads sprites from the community [maplestory.io](https://maplestory.io) API
  (GMS v270). Change the IDs at the top (pet, chair, outfit) and run it again to swap assets:

  ```sh
  pip install pillow
  python3 build_assets.py
  ```
