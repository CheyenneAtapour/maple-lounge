# Maple Lounge

A small browser prototype for a MapleStory fashion/hangout game, set on a Halloween night.
Walk around, jump, and sit on the Rabbit Lamp Chair (it changes color each time, like in game)
while your pet follows you. The wardrobe on the right swaps pets, hats, outfits, capes, shoes,
face accessories, and weapons, with a Halloween-themed selection.

**Play:** https://www.cheyenneatapour.com/maple-lounge/

## Controls

| Key | Action |
|---|---|
| ← → / A D | Walk |
| Space / ↑ / W | Jump |
| ↓ / S (near the lamp) | Sit; any move key stands up |
| Click your pet | Pet it |

## How it works

- `index.html` is the whole game: a canvas, movement, pet follow logic, the chair, the scenery,
  and the wardrobe.
- `assets.js` holds the default look, Adriano, the chair, the wardrobe list, and scenery metadata,
  generated by `build_assets.py`. Scenery images and wardrobe icons live in `assets/`.
- Outfit changes and non-default pets are fetched live from maplestory.io (renders are queued and
  retried, since the free API errors under bursts). The default look and Adriano work offline.
- `build_assets.py` downloads sprites from the community [maplestory.io](https://maplestory.io) API
  (GMS v270). Change the IDs at the top (pet, chair, outfit, wardrobe, scenery) and run it again:

  ```sh
  pip install pillow
  python3 build_assets.py
  ```
